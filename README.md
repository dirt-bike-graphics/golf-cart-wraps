## Reference scope

The catalog describes visual body configurations. It provides no physical dimensions, DPI specification or production cut templates. Reference years do not establish interchangeability.

## Related

I built [Golf Cart Wraps](https://golfcart-wraps.com) to help owners explore artwork on their cart. Use this reference to compare body styles, then [try your pattern in the 3D designer](https://golfcart-wraps.com/design?utm_source=github&utm_medium=referral&utm_campaign=open_reference).
